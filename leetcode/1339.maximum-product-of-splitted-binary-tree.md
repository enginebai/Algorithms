# [1339. Maximum Product of Splitted Binary Tree](https://leetcode.com/problems/maximum-product-of-splitted-binary-tree/description/)

## Derivation
- Abstraction: For each root, we split it from the entire tree, we calculate the sum of the two subtrees and product of the two sum. → The sum of the remaining tree after split is `TOTAL SUM - sum(current root)` = `sum(top-level root) - sum(current root)`.

- Brute force: 
   - Calculate total sum of top-level root.
   - Traverse the tree to iterate all roots to split, calculate the sum of current root and product, update the larger ones to answer.

```kotlin
fun maxProduct(root: TreeNode?): Int {
    val total = sum(root)
    return split(root, total)
}

private fun split(root: TreeNode?, total: Int): Int {
    if (root == null) return 0
    val sum = sum(root)
    val another = total - sum

    val left = split(root.left, total)
    val right = split(root.right, total)
    return maxOf(sum * another, left, right)
}

private fun sum(root: TreeNode?): Int {
    if (root == null) return 0
    val left = sum(root.left)
    val right = sum(root.right)
    return root.`val` + left + right
}
```

- Bottleneck analysis: For each root, we have to calculate the sum of the current root. If we traverse in top-down approach, we will re-calculate the same subtree multiple times. `O(n^2)`

    ```js
    A - B - C // treat it as skew tree

    split(A) 
        sum(A) = A + sum(B)
    split(B)
        sum(B) = B + sum(C)
    split(C)
        sum(C) = C + sum(null)
    ```
    Top-down: `split(A) → split(B)`, `split(A)` calculates `sum(B)`, and `split(B)` calculates again, it's repeated work.

- Pattern recognition: What if we can store the sum of each node for reuse? Or we can change the traversal direction to bottom-up?!

   - `split(C)` calculates `sum(C)`
   - `split(B)` reuses `sum(C) + B` for `sum(B)`
   - So on…

```kotlin
private val MOD = 1_000_000_007
private var maxProduct = 0L
fun maxProduct(root: TreeNode?): Int {
    val total = sum(root)
    sumAndSplit(root, total)
    return (maxProduct % MOD).toInt()
}

private fun sum(root: TreeNode?): Long {
    if (root == null) return 0L
    return root.`val`.toLong() + sum(root.left) + sum(root.right)
}

private fun sumAndSplit(root: TreeNode?, total: Long): Long {
    if (root == null) return 0L
    val left = sumAndSplit(root.left, total)
    val right = sumAndSplit(root.right, total)
    val currentSum = root.`val`.toLong() + left + right
    maxProduct = maxOf(maxProduct, currentSum * (total - currentSum))
    return currentSum
}
```

## Postorder
For a root node, how can we split into two subtrees to get the product of the sums of the subtrees?
```js
     10     
    /  \    
   3    4

// Can split into two cases
     10             10
       \     or    /
   X    4         3    X
 
 = 3 * 14    or   13 * 4
```
If we split the left child, for example, then the product will be `3 * (10 + 4)`, which is `the sum of the left subtree` x `total sum - the left subtree`. (The same for the right child)

So for any root node, we can calculate the left subtree sum and the right subtree sum, and then
* Split left = `sum(left) * (total sum - sum(left))`
```js
         root
               \
sum(left)    sum(right)
```
* Split right = `(total sum - sum(right)) * sum(right)`
```js
         root
     /
sum(left)    sum(right)
```

We compute the total sum of the tree first, then use postorder to compute subtree sums and update the maximum product while computing the sum of the tree.

```kotlin
private val mod = 10_000_000_007
private var maxProduct = 0L
private var total = 0L

fun maxProduct(root: TreeNode?): Int {
    total = sum(root)
    sum(root)
    return (maxProduct % mod).toInt()
}

private fun sum(root: TreeNode?): Long {
    if (root == null) return 0L
    //      5
    //    /   \
    //   2     3
    // total = 10
    val left = sum(root.left) // 2
    val right = sum(root.right) // 3

    val leftSplit = left * (total - left)       // 2 * (10 - 2)
    val rightSplit = (total - right) * right    // (10 - 3) * 3
    maxProduct = maxOf(maxProduct, maxOf(leftSplit, rightSplit))

    return root.`val`.toLong() + left + right
}
```

Or the same idea, we can split at root node:
```js
 parent
    \
    ---  // split here when calculating the sum of `root`
      \
       root     sum(root)
      /    \
    left  right
```

```kotlin
fun maxProduct(root: TreeNode?): Int {
    total = sum(root)
    sum(root)
    return (maxProduct % mod).toInt()
}

private fun sum(root: TreeNode?): Long {
    if (root == null) return 0L
    val currentSum = root.`val` + sum(root.left) + sum(root.right)
    maxProduct = maxOf(maxProduct, currentSum * (total - currentSum))
    return currentSum
}
```

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(n)`
