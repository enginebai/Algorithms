# [1248. Count Number of Nice Subarrays](https://leetcode.com/problems/count-number-of-nice-subarrays/description/)

## Sliding Window
We check the number of subarrays which have exactly `k` odd numbers in a subarray, we can transform this problem into: 

> Exact `K` times = At most `K` times - At most `K - 1` times

To find the number of subarray with at most `K` odd numbers, we can use sliding window.
```kotlin
fun numberOfSubarrays(nums: IntArray, k: Int): Int {
    return atMost(nums, k) - atMost(nums, k - 1)
}

private fun atMost(nums: IntArray, k: Int): Int {
    var left = 0
    var count = 0
    var answer = 0
    for (right in nums.indices) {
        if (nums[right] % 2 != 0) count++
        while (left <= right && count > k) {
            if (nums[left] % 2 != 0) count--
            left++
        }
        // 越短越合法
        answer += right - left + 1
    }
    return answer
}
```


## Prefix Sum + Hash Table
We define `prefix(i)` as the number of odd numbers in the subarray `nums[0..i]`. Then we can find the number of subarrays with exactly `k` odd numbers by counting the number of pairs `(i, j)` such that `prefix(j) - prefix(i) = k`, which is equivalent to `prefix(i) = prefix(j) - k`. 

We can use a hash table to store the prefix sum we've seen so far. We iterate `j` to calculate `prefix(j)`, then check if `prefix(j) - k` exists in the hash table (looking for `prefix(i - 1)`). The idea is very similar to [560. Subarray Sum Equals K](../leetcode/560.subarray-sum-equals-k.md). 
```kotlin
fun numberOfSubarrays(nums: IntArray, k: Int): Int {
    var answer = 0
    val countMap = HashMap<Int, Int>()
    countMap[0] = 1
    var count = 0
    for (num in nums) {
        if (num % 2 != 0) count++
        if (count - k in countMap) {
            answer += countMap[count - k]!!
        }
        countMap[count] = (countMap[count] ?: 0) + 1
    }
    return answer
}
```
