# [2063. Vowels of All Substrings](https://leetcode.com/problems/vowels-of-all-substrings/)

## Prefix Sum
To calculate the sum of subarray, we can use prefix sum:

```js
A, B, C, D, E
   i     j

prefix[j] - prefix[i - 1] = sum of A[i..j]
```

The original problem is asking to calculate the sum of vowels in all substrings. 

```js
// Iterate (end of j)
A, B, C, D
   i     j
A           prefix[A]

A, B        prefix[B]
   B        prefix[B] - prefix[A]
       +) = prefix[B] * 2 - prefix[A]
          

A, B, C     prefix[C]
   B, C     prefix[C] - prefix[A]
      C     prefix[C] - prefix[B]
       +) = prefix[C] * 2 - prefix[A, B] 

A, B, C, D  prefix[D]
   B, C, D  prefix[D] - prefix[A]
      C, D  prefix[D] - prefix[B]
         D  prefix[D] - prefix[C] = 4 * prefix[D] - prefix[A, B, C]
```

We can transform it into the following formula:
```js
_, _, _, _, i, _, _

for i in 0 until n: 
    sum of `(i + 1) * prefix[i] - sumOf(prefix[0..i - 1])`
```

Current prefix sum of `i` times `(i + 1)` - sum of all the previous prefix sum.

```kotlin
private val vowels = setOf('a', 'e', 'i', 'o', 'u')

fun countVowels(word: String): Long {
    val n = word.length

    // calculate prefix sum array
    val prefixArray = LongArray(n)
    var prefixSum = 0L
    for (i in 0 until n) {
        if (word[i] in vowels) prefixSum++
        prefixArray[i] = prefixSum
    }
    
    var answer = 0L
    var sumOfPrefixSum = 0L // for sumOf(prefix[0..i - 1])
    // iterate i from 0 until n
    for (i in 0 until n) {
        // sum of `(i + 1) * prefix[i] - sumOf(prefix[0..i - 1])`
        answer += (i + 1).toLong() * prefixArray[i] - sumOfPrefixSum
        
        // accumulate to sumOf(prefix[0..i - 1])
        sumOfPrefixSum += prefixArray[i]
    }
    return answer
}
```

We can simplify the implementation since we just need to keep track of the current prefix sum and the sum of all previous prefix sums.

```kotlin
fun countVowels(word: String): Long {
    val n = word.length
    var prefixSum = 0L
    var answer = 0L
    var sumOfPrefixSum = 0L // for sumOf(prefix[0..i - 1])
    // iterate i from 0 until n
    for (i in 0 until n) {
        if (word[i] in vowels) prefixSum++

        // sum of `(i + 1) * prefix[i] - sumOf(prefix[0..i - 1])`
        answer += (i + 1).toLong() * prefixSum - sumOfPrefixSum
        
        // accumulate to sumOf(prefix[0..i - 1])
        sumOfPrefixSum += prefixSum
    }
    return answer
}
```

## Contribution
不要問「這個子字串包含多少個母音」，而是倒過來問「這個母音字元，會被多少子字串包含到」。假設字串長度為 `n`，在 `i` 有一個母音，那麼任何包涵 `i` 的子字串 `word[L..R]` 的範圍必須涵蓋 `i`：
- 左邊界 `L`：可以是 0, 1, 2, ..., i，總共有 `i + 1` 種可能。
- 右邊界 `R`：可以是 i, i + 1, i + 2, ..., n - 1，總共有 `n - i` 種可能。

左右邊界的組合總數就是兩個相乘 `(i + 1) * (n - i)`，也就是這個母音字元的「貢獻」總數。我們只需要把每個母音字元的貢獻值加總即可。

貢獻法的本質是：我們不去問每個子字串「你裡面有多少母音？」，而是**站在某個母音字元的視角，看它能被多少左邊界 x 又邊界的子字串組合包進來。**

我們來拆解怎麼算出「貢獻值」：
- 為何要看 `L..R`?
    - 任何子字串 `word[L..R]` 在本質上就是選定「左邊界」和「右邊界」所圈起來的區域。
    - 如果母音字元在 `i` 要被包進去，那麼左右邊界一定要把 `i` 夾起來，也就是左邊界必須在 `i` 的左邊 (或踩在 `i` 上)，右邊界同理。
- 知道左右邊界，要怎麼算出有多少種組合？
    - 左邊界有 `i + 1` 種可能，右邊界有 `n - i` 種可能，兩者相乘就是總共的組合數。
    - 為何用「相乘」？是因為選擇「左邊界」和「右邊界」是兩個完全獨立的搭配，可以想像我們有 `i + 1` 件上衣和 `n - i` 件褲子，總共可以搭配出 `(i + 1) * (n - i)` 套裝。

```js
fun countVowels(word: String): Long {
    val n = word.length
    var answer = 0L
    for (i in word.indices) {
        if (word[i] in vowels)
            answer += (i + 1).toLong() * (n - i)
    }
    return answer
}
```
