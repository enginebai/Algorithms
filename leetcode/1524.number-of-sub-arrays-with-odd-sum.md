# [1524. Number of Sub-arrays With Odd Sum](https://leetcode.com/problems/number-of-sub-arrays-with-odd-sum/)

- Goals: Find the # of subarray sum is odd.
- Abstraction: Sum of subarray `[i..j]` is `prefix(j) - prefix(i - 1)`, we count how many of prefix diff is odd.
- Brute force:

   - Iterate outer `j` to calculate `prefix(j)`

      - Check if `prefix(j)` is odd first.

      - Iterate inner `i` from `0 to j - 1` to calculate `prefix(i - 1)`

         - Check if prefix diff is odd

```kotlin
fun bruteForce(arr: IntArray): Int {
    var prefixJ = 0L
    var answer = 0L
    for (j in arr.indices) {
        prefixJ += arr[j].toLong()
        if (prefixJ % 2L != 0L) {
            answer++
            answer %= MOD
        }

        var prefixI = 0L
        for (i in 0 until j) {
            prefixI += arr[i].toLong()
            val prefixDiff = prefixJ - prefixI
            if (prefixDiff % 2L != 0L) {
                answer++
                answer %= MOD
            }
        }
    }
    return answer.toInt()
}
```

- Time complexity: `O(n^2)`

- Bottleneck: For each `j`, we recalculate the prefix sum of `i`, it’s a waste from moving from `j` to `j + 1`, we only add `arr[j + 1]` to prefix sum.

- Pattern recognition:

| `prefix(i - 1)` | `prefix(j)` | Sum | 
|---|---|---|
| odd | odd | even | 
| even | odd  | odd | 
| odd | even | odd | 
| even | even | even | 

Keep track of the number of odd and even sum we’ve seen before. → Hash table or variables.

The prefix diff is odd if:

- `prefix(j)` is odd, `prefix(i - 1)` must be even → we check how many even prefix sum we’ve seen so far.

- `prefix(j)` is even, `prefix(i - 1)` must be odd → we check how many odd prefix sum we’ve seen so far.

```kotlin
fun numOfSubarrays(arr: IntArray): Int {
    var prefixJ = 0L
    var answer = 0L
    var oddBefore = 0L
    var evenBefore = 0L

    for (j in arr.indices) {
        prefixJ += arr[j].toLong()
        if (prefixJ % 2L != 0L) { // Check prefix(j) is odd, subarray[0..j].
            answer++
            answer %= MOD
        }
        // Check prefix(j) - prefix(i - 1) is odd.
        if (prefixJ % 2L == 0L) {
            answer += oddBefore
            answer %= MOD
            evenBefore++
        } else {
            answer += evenBefore
            answer %= MOD
            oddBefore++
        }
    }
    return answer.toInt()
}
```
