# [1155. Number of Dice Rolls With Target Sum](https://leetcode.com/problems/number-of-dice-rolls-with-target-sum/)

## Dynamic Programming
We are distributing a target value across exactly `N` buckets (dice), where each bucket has a strict capacity limit of `1` to `K`.

```js
   1, 2, ..., K
   1, 2, ..., K
+) 1, 2, ..., K
---------------
         target
```

How it works? Now we're rolling 3 dice, target == 10, if 3rd die rolls 4, then it implies our first 2 dice must have summed to 6. If 3rd die rolls 5, then first 2 dice must have summed to 5, so on. Therefore, the ways to get 10 with dices is the sum of all valid ways to reach `(10 - face value)` using `(N - 1)` dices.
```js
   1, 2, ..., K = 2
      ^
   1, 2, ..., K = 2 + 1
   ^
+) 1, 2, ..., K = 2 + 1 + ... + K
              ^
---------------
         target
```

To check if `target` can be reached with `N` dice, we can check if `target - i` can be reached with `N - 1` dice, where `i` is the value of the last die. This leads to the following recurrence relation:

$$DP[d][t] = \sum_{f=1}^{k} DP[d-1][t-f] \pmod{10^9+7}$$

And base case is when we have 0 dice and target is 0, there is exactly 1 way to reach it (by rolling nothing).

```kotlin
private val MOD = 1_000_000_007
fun numRollsToTarget(n: Int, k: Int, target: Int): Int {
    // val memo = Array(n + 1) { IntArray(target + 1) { -1 }}
    // return topDown(n, k, target, memo)
    return bottomUp(n, k, target)
}

private fun topDown(n: Int, k: Int, target: Int, memo: Array<IntArray>): Int {
    if (n == 0 && target == 0) return 1
    if (n <= 0 || target <= 0) return 0
    if (memo[n][target] != -1) return memo[n][target]
    var count = 0L
    for (i in 1..k) {
        count += topDown(n - 1, k, target - i, memo).toLong()
        count %= MOD
    }
    memo[n][target] = count.toInt()
    return count.toInt()
}

private fun bottomUp(n: Int, k: Int, target: Int): Int {
    val dp = Array(n + 1) { IntArray(target + 1) }
    dp[0][0] = 1
    for (dice in 1..n) {
        for (t in 1..target) {
            var count = 0L
            for (kk in 1..k) {
                if (t - kk >= 0) {
                    count += dp[dice - 1][t - kk]
                    count %= MOD
                }
            }
            dp[dice][t] = count.toInt()
        }
    }
    return dp[n][target]
}
```
- **Time Complexity:** 
    - Top-down without memo: `O(K^n)`, for every die, there are `K` possible face values, this branching repeats for exactly `n` dice until it hits 0.
    - Top-down with memo: `O(n * target * K)`, for each `topDown()`, we have total `n * target` unique states, and each state has `K` iterations to check all possible face values.
    - Bottom-up: `O(n * target * K)`.
- **Space Complexity:** `O(n * target)` for the memo or DP table, `O(n)` for the recursion stack.
