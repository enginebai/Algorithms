# [1438. Longest Continuous Subarray With Absolute Diff Less Than or Equal to Limit](https://leetcode.com/problems/longest-continuous-subarray-with-absolute-diff-less-than-or-equal-to-limit/)

## Derivation
- Abstraction: Find the longest subarray such that `abs(max - min) ≤ limit`, where `max` and `min` is the maximum and minimum in that subarray. Absolute diff of any pair of two elements ≤ `limit`: the `abs(max - min)` must ≤ `limit`

- Brute force:

   - Generate all possible subarrays. (2 ways: fix `start` or fix `end`)

   - We update the `max` and `min` in that subarray when iterating. If `abs(max - min) ≤ limit`, update the answer.

   - `O(N^2)` for generating all subarrays + iteration of subarray `O(n)` → Total = `O(n^3)`

- Bottleneck analysis:

   ```kotlin
   A
   A, B // If B is the max and |max-min| > limit
   A, B, C // Then checking C, D is redundant
   A, B, C, D
   
   _, _, X, Y, Z, ....
      ^ -> 
   ```

   1. If `|max - min|` > limit when adding `X`: Then all the subarray later that includes `X` will be invalid too. `[_, _, X, Y]` `[…, X, Y, Z]`, … **當目前長度的滑窗無效時，那麼更長的滑窗也是無效。**

   2. Based on point 1, the starting index become invalid now, so we should move the starting position that make `|max - min| ≤ limit` again. (Find the next valid starting position)

- Pattern recognition: Sliding window.

   - Window: The subarray where `|max - min| ≤ limit`

   - Expand the window while the condition holds, shrink when breaking and until the condition holds again.

   - We have to maintain the maximum and minimum while expanding or shrinking the window. → Need a efficient way to find the extrema that supported addition + subtraction. → Sliding window max or min.

```kotlin
fun longestSubarray(nums: IntArray, limit: Int): Int {
    var answer = 0
    var left = 0
    val windowSet = TreeSet<Int> { i1, i2 -> nums[i2] - nums[i1] } // Index, sort value in descending order
    val windowCountMap = HashMap<Int, Int>() // Value, frequency
    for (right in nums.indices) {
        windowSet.add(right)
        windowCountMap[nums[right]] = (windowCountMap[nums[right]] ?: 0) + 1
        while (nums[windowSet.first()] - nums[windowSet.last()] > limit) {
            val count = (windowCountMap[nums[left]] ?: 0) - 1
            if (count > 0) {
                windowCountMap[nums[left]] = count
            } else {
                windowCountMap.remove(nums[left])
                windowSet.remove(left)
            }
            left++
        }
        answer = maxOf(answer, right - left + 1)
    }
    return answer
}

// 修正。
fun longestSubarray(nums: IntArray, limit: Int): Int {
    var answer = 0
    var left = 0

    // 修正 Comparator：數值不同比數值，數值相同比 index
    val windowSet = TreeSet<Int> { i1, i2 ->
        if (nums[i1] != nums[i2]) {
            nums[i2].compareTo(nums[i1]) // 數值：大到小
        } else {
            i2.compareTo(i1)            // Tie-breaker：Index 不同就不會回傳 0
        }
    }

    for (right in nums.indices) {
        windowSet.add(right)

        // first() 是最大值，last() 是最小值
        while (nums[windowSet.first()] - nums[windowSet.last()] > limit) {
            // 直接精準移除離開窗口的 left 索引，不需要 HashMap！
            windowSet.remove(left)
            left++
        }

        answer = max(answer, right - left + 1)
    }

    return answer
}
```
