回到原題，題目真正在找的是子序列「任意兩個相鄰數字相加」的奇偶性必須相同。

在 `(a + b) % 2` 的結果來看兩個數字的可能性：
1. even = (odd + odd) or (even + even)
    * 所有都是 odd
    * 所有都是 even
2. odd = (even + odd) or (odd + even)
    * 偶數開頭交替 `[偶, 奇, 偶, 奇, ...]`
    * 奇數開頭交替 `[奇, 偶, 奇, 偶, ...]`

滿足題目的子序列就是這 4 種模式，然後我們找最長的那個即可。

```kotlin
fun maximumLength(nums: IntArray): Int {
    var allOdd = 0
    var allEven = 0
    for (i in nums.indices) {
        if (nums[i] % 2 == 0) {
            allEven++
        } else {
            allOdd++
        }
    }

    /**
     * Find odd, even, odd, even, ... or even, odd, even, odd, ...
     */
    fun countAlternative(init: Boolean): Int {
        var count = 0
        var needEven = init
        for (i in nums.indices) {
            if (nums[i] % 2 == 0 && needEven) {
                count++
                needEven = false
            } else if (nums[i] % 2 != 0 && !needEven) {
                count++
                needEven = true
            }
        }
        return count
    }

    val oddEven = countAlternative(false)
    val evenOdd = countAlternative(true)
    return maxOf(allOdd, allEven, oddEven, evenOdd)
}
```
