# [1670. Design Front Middle Back Queue](https://leetcode.com/problems/design-front-middle-back-queue/description/)

## Queues
We need to support the special access to the middle element, according to the problem definition of middle element, the results before and after middle operation:
- If the number of elements is odd: `[a, b, c]`
    - Push middle: `[a, X, b, c]`
    - Pop middle: `[a, c]`
- If the number of elements is even: `[a, b, c, d]`
    - Push middle: `[a, b, X, c, d]`
    - Pop middle: `[a, c, d]`

If we just access the front and back of the queue, we can use a single queue to store the elements. But to support `O(1)` to access the middle element, we can use two queues to store the first half and the second half of the elements, so that we can get it from the last of the 1st half or the first of the 2nd half.

```js
[_, _, X] / [_, _, _]
// Or
[_, _, _] / [X, _, _]
```

But there is a problem when the number of elements is odd, we need to decide which half to put the middle element. 

### Push Middle in Second Half
We always keep second half >= first half at most by 1, so every time we push or pop (no matter front, middle, or back), we need to rebalance the two queues.

Decide which half queue and which side to push / pop middle element according to the size.
- Odd size `[a, b, c]`, the two queues store `[a] / [b, c]`.
    - Push middle: `[a, X] / [b, c]`, add `X` to the last of 1st half.
    - Pop middle: `[a] / [c]`, remove the first of 2nd half.
- Even size `[a, b, c, d]`, the two queues store `[a, b] / [c, d]`.
    - Push middle: `[a, b] / [X, c, d]`, add `X` to the first of 2nd half.
    - Pop middle: `[a] / [c, d]`, remove the last of 1st half.

```kotlin
class FrontMiddleBackQueue() {

    private val first = ArrayDeque<Int>()
    private val second = ArrayDeque<Int>()

    fun pushFront(`val`: Int) {
        first.addFirst(`val`)
        rebalance()
    }

    fun pushMiddle(`val`: Int) {
        if (size % 2 != 0) {
            first.addLast(`val`)
        } else {
            second.addFirst(`val`)
        }
        rebalance()
    }

    fun pushBack(`val`: Int) {
        second.addLast(`val`)
        rebalance()
    }

    fun popFront(): Int {
        if (size == 0) return -1
        // Remember null check from first queue, for the size == 1, `[] / [a]`, the first queue is empty, we need to pop from second queue.
        val value = first.removeFirstOrNull() ?: second.removeFirst()
        rebalance()
        return value
    }

    fun popMiddle(): Int {
        if (size == 0) return -1
        val value = if (size % 2 != 0) {
            second.removeFirst()
        } else {
            first.removeLast()
        }
        rebalance()
        return value
    }

    fun popBack(): Int {
        if (size == 0) return -1
        val value = second.removeLast() // No need to check null, because if size > 0, second queue is not empty.
        rebalance()
        return value
    }

    private val size get() = first.size + second.size

    /**
     * We rebalance every time we push or pop, the size difference is at most 1, so 
     * we just compare and move directly, no need to check the size difference.
     */
    private fun rebalance() {
        if (first.size > second.size) {
            second.addFirst(first.removeLast())
        } else if (first.size < second.size - 1) {
            first.addLast(second.removeFirst())
        }
    }

}
```

### Pop Middle in First Half
The second way is to always keep 1st half >= 2nd half at most by 1. The update rules:
- Odd size `[a, b, c]`, the two queues store `[a, b] / [c]`.
    - Push middle: `[a, X] / [b, c]`, **we move the last element of 1st to the first of 2nd** and add `X` to the last of 1st half.
    - Pop middle: `[a] / [c]`, remove the last of 1st half.
- Even size `[a, b, c, d]`, the two queues store `[a, b] / [c, d]`.
    - Push middle: `[a, b, X] / [c, d]`, add `X` to the last of 1st half.
    - Pop middle: `[a] / [c, d]`, remove the last of 1st half.
    
```kotlin
class FrontMiddleBackQueue() {

    private val first = ArrayDeque<Int>()
    private val second = ArrayDeque<Int>()

    fun pushFront(`val`: Int) {
        first.addFirst(`val`)
        rebalance()
    }

    fun pushMiddle(`val`: Int) {
        if (size % 2 != 0) {
            second.addFirst(first.removeLast())
        }
        first.addLast(`val`)
        rebalance()
    }

    fun pushBack(`val`: Int) {
        second.addLast(`val`)
        rebalance()
    }

    fun popFront(): Int {
        if (size == 0) return -1
        val value = first.removeFirst() // No need to check null, because if size > 0, first queue is not empty.
        rebalance()
        return value
    }

    fun popMiddle(): Int {
        if (size == 0) return -1
        val value = first.removeLast()
        rebalance()
        return value
    }

    fun popBack(): Int {
        if (size == 0) return -1
        // Remember null check from second queue, for the size == 1, `[a] / []`, the second queue is empty, we need to pop from first queue.
        val value = second.removeLastOrNull() ?: first.removeLast()
        rebalance()
        return value
    }

    private val size get() = first.size + second.size

    private fun rebalance() {
        if (first.size - 1 > second.size) {
            second.addFirst(first.removeLast())
        } else if (first.size < second.size) {
            first.addLast(second.removeFirst())
        }
    }
}
```
