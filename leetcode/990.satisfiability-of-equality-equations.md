# [990. Satisfiability of Equality Equations](https://leetcode.com/problems/satisfiability-of-equality-equations/)

## Derivation
### Abstractions
To determine if a set of equations is locally valid, we must verify that no two variables are simultaneously `a == b` and `a != b`. The optimal approach build groups (equivalence classes) out of all the `==` equations first, then check the inequality `!=` equations to ensure no two variables in `!=` belong to the same group.

How to check if two variables belong to the same group? The core rule: **Transitivity**. If `a == b` and `b == c`, then `a == c`. If the variables (`a`, `b`, `c`) belong to the same group, they must be connected by a chain of `==` equations (`a - b - c`). This is a classic *connected components* problem. For `x != y`, we're asking "Do the two variables belong to the same connected component?" If they do, then the equation is invalid.

### Brute Force
- We build a graph from `==` equations, then check all `!=` equations to see if the two variables belong to the same connected component via DFS or BFS (If there exists a path between the two variables).

> Pathfinding directly simulates the *transitivity* of equality. If `a == b` and `b == c`, then we can find a path from `a` to `c` through `b`. If there exists a path between two variables, they belong to the same connected component.

### Bottleneck Analysis
We have iterate all `!=` equations, then run a full DFS/BFS graph traversal which takes `O(V + E)` time. We are repeatedly tracing the same connected components to answer the same questions: "Are these variables grouped together?".

### Pattern Recognition
We need a way to track connected components such that checking if two variables are in the same group efficiently rather than traversing the whole graph every time. This is a classic *Union-Find* problem. We can use a Union-Find data structure to group variables together and check if two variables belong to the same group in `O(1)` time.

```kotlin
fun equationsPossible(equations: Array<String>): Boolean {
    val parent = IntArray(26)
    for (i in parent.indices) {
        parent[i] = i
    }

    fun find(x: Int): Int {
        var root = x
        while (root != parent[root]) {
            parent[root] = parent[parent[root]]
            root = parent[root]
        }
        return root
    }

    fun union(x: Int, y: Int) {
        val parentX = find(x)
        var parentY = find(y)
        if (parentX != parentY) {
            parent[parentY] = parentX
        }
    }

    for (equation in equations) {
        if (equation[1] == '=') {
            val x = equation[0] - 'a'
            val y = equation[3] - 'a'
            union(x, y)
        }
    }
    for (equation in equations) {
        if (equation[1] == '!') {
            val x = equation[0] - 'a'
            val y = equation[3] - 'a'
            if (find(x) == find(y)) {
                return false
            }
        }
    }
    return true
}
```

Or we still can use DFS/BFS graph traversal to find connected components, but we assign each component a unique ID, then we can check if two variables belong to the same component in `O(1)` time.

```kotlin
fun equationsPossible(equations: Array<String>): Boolean {
    val graph = Array(26) { ArrayList<Int>() }
    for (equation in equations) {
        if (equation[1] == '=') {
            val a = equation[0] - 'a'
            val b = equation[3] - 'a'
            graph[a].add(b)
            graph[b].add(a)
        }
    }
    var id = 1
    val componentIds = IntArray(26) { -1 }
    for (i in graph.indices) {
        if (componentIds[i] == -1) {
            dfs(graph, i, id++, componentIds)
        }
    }

    for (equation in equations) {
        if (equation[1] == '!') {
            val a = equation[0] - 'a'
            val b = equation[3] - 'a'
            if (a == b || componentIds[a] == componentIds[b]) return false
        }
    }
    return true
}

private fun dfs(graph: Array<ArrayList<Int>>, i: Int, id: Int, componentIds: IntArray) {
    if (componentIds[i] != -1) return
    componentIds[i] = id
    for (adj in graph[i]) {
        dfs(graph, adj, id, componentIds)
    }
}
```
