# [2033. Minimum Operations to Make a Uni-Value Grid](https://leetcode.com/problems/minimum-operations-to-make-a-uni-value-grid/)

## Derivation

### Abstraction
It doesn’t matter for grid, we can treat it as `nums` 1D array.

```js
[1, 4], x = 1
target = 1 or 4, [0,-3] [+3, 0]
target = 2 or 3, [+1,-2] []

[2,4,6,8] x = 2
target=2 [0,1,2,3] = 6
target=4 [1,0,1,2] = 4
target=6 [2,1,0,1] = 4
target=8 [3,2,1,0] = 6

[1,2,3,4] x = 2
target = 1 [0,X,1,X]
target = 2 [X,0,X,1]
target = 3 [1,X,0,X]
target = 4 [X,1,X,0]

// target is not any of nums[i]
[1,5] x = 2
target = 1 [0,2]
target = 2 [X,X]
target = 3 [1,1]
target = 4 [X,X]
target = 5 [2,0]
```

To find a target `X` such that all `(X - nums[i])` are dividable by `X` and sum of `nums[i] / X` is minimum.

- Plot all points on Y axis, find the horizontal line of target Y so that the sum of all the distance of each number is minimum and dividable.

### Brute Force
- Try all numbers between `min(nums[i])..max(nums[i])` to check the target `X` so that number of operations is minimum.

- TC: `O(R x N)` where `R` is the range of input `max - min`.

### Bottleneck Analysis

> 這是我當時卡住的地方，我不會找瓶頸在哪？哪裡有重複或者不必要的計算。

降維提示：
- 兩個點: 數線上只有 $A$ 和 $B$ ($A < B$)，你要選一個點 $T$，使得 $\vert{}T - A\vert{} + \vert{}T - B\vert{}$ 最小。$T$ 應該落在什麼範圍內？

    ```js
    ----A-----------B----
        ^     ^     ^
        T1    T2    T3
    ```
    - T1: 0 + |A-T1| = |AB|
    - T2: |A-T2| + |T2-B| = |AB|
    - T3: |A-T3| + 0 = |AB|
    - 結論：只要是落在 `[A, B]` 之間的點，總距離都是最小值。
- 三個點: 數線上有 $A < B < C$，你要選一個點 $T$ 讓距離和最小。如果 $T$ 落在 $B$ 的左邊或右邊，總距離會如何變化？
    
    ```js
    ----A----------B--------------C----
        ^    ^     ^       ^      ^
        T1   T2    T3      T4     T5
    ```
    - T1: 0 + |T1-B| + |T1-C| = |AB| + |AC|
    - T2: |A-T2| + |T2-B| + |T2-C| = |AB| + |T2-B| + |BC|
    - T3: |A-T3| + 0 + |T3-C| = |AB| + |BC|
    - T4: |A-T4| + |B-T4| + |T4-C| = |AB| + |B-T4| + |BC|
    - T5: |A-T5| + |B-T5| + 0 = |AC| + |BC|
    - 結論：只有選擇 `B` 才能得到最小距離和。

從上述降維提示來看，我們可以擴展到有 N 個數字，最終可選的 `T` 必定是 `[A..B]` 之間的數字或者是 `B`，也就是**中位數**，也就是我們算 `min(nums[i])..max(nums[i])` 大部分都是浪費多餘的，除了中位數之外其他都不會是最佳解，所以我們可以把暴力解的範圍從 `min..max` 降維到 `median`。

```js
n = 4
... -X--------A-----------B--------Y- ...
              |-----T-----|

n = 5
... -X----A----------B--------------C----Y- ...
                T
```

然而我們可以再更簡化 `[A..B]` 這個情況，從上面「兩個點」的情況來看，我們選 `T2 in [A..B]` 的答案都跟選 `A` 或者 `B` 是一樣的，所以其實中位數我們只需要算 `nums[n / 2]` 即可。

#### Q: 為何是「中位數」？
選「中位數」是因為站在正中間時，**左右兩邊拉扯你的力量剛好達到平衡**。

證明：剝洋蔥法 (邊界配對)

想像最左邊的人 $A$ 與最右邊的人 $B$ 兩個人站在最外側。
1. 你可以選擇在 `A..B` 之間任意一個位置 `X`，而 `|AX|` + `|XB|` 都是固定的 `|AB|`，這個距離和不會變。(同上面的兩個點的情況)
2. 既然只要站在 A 和 B 之間的任意一個位置，距離都是最小而且固定，那麼我們就可以無視這兩個人，像洋蔥一樣把最外層剝掉。
3. 接著看第二外層的兩個人，重複步驟 1. 2. 把第二層剝掉。
4. 重複剝掉外層，最後剩下：
    - 奇數個人，最後剩下中間的那個人，那麼直接踩在他身上距離會最小 0。
    - 偶數個人，最後剩下中間的兩個人。那麼站在他們中間任意位置，距離都是最小而且固定 (同步驟 1.)。
這樣重複剝掉外層最後剩下的，就是 **中位數**。

```kotlin
fun minOperations(grid: Array<IntArray>, x: Int): Int {
    val m = grid.size
    val n = grid[0].size
    val array = IntArray(m * n)
    var k = 0
    val mod = grid[0][0] % x
    for (i in 0 until m) {
        for (j in 0 until n) {
            array[k++] = grid[i][j]
        }
    }
    array.sort()
    val target = array[m * n / 2]
    var answer = 0
    for (i in array.indices) {
        val diff = abs(target - array[i])
        if (diff % x != 0) return -1
        answer += diff / x
    }
    return answer
}
```

- **Time Complexity:** `O(N log N)` where `N = m * n` is the number of elements in the grid. Sorting the array takes `O(N log N)`, and calculating the operations takes `O(N)`.
- **Space Complexity:** `O(N)` for storing the elements of the grid in a 1D array.

## Quickselect
這題其實不需要完整排序，我們只需要拿到 `[N / 2]` 的中位數就好，所以可以使用 Quickselect 來降低時間複雜度到 `O(N)` 平均時間。

```kotlin
fun minOperationsOptimal(grid: Array<IntArray>, x: Int): Int {
    val m = grid.size
    val n = grid[0].size
    val total = m * n
    val array = IntArray(total)
    val base = grid[0][0]
    var k = 0

    for (i in 0 until m) {
        for (j in 0 until n) {
            val current = grid[i][j]
            if (Math.abs(current - base) % x != 0) return -1
            array[k++] = current
        }
    }

    // 使用 Quickselect 在 O(N) 平均時間找到中位數
    val medianIndex = total / 2
    quickSelect(array, 0, total - 1, medianIndex)
    val median = array[medianIndex]

    var answer = 0
    for (num in array) {
        answer += Math.abs(num - median) / x
    }
    return answer
}

private fun quickSelect(nums: IntArray, left: Int, right: Int, k: Int) {
    if (left >= right) return
    val pivotIndex = partition(nums, left, right)
    when {
        pivotIndex == k -> return
        pivotIndex < k -> quickSelect(nums, pivotIndex + 1, right, k)
        else -> quickSelect(nums, left, pivotIndex - 1, k)
    }
}

private fun partition(nums: IntArray, left: Int, right: Int): Int {
    val pivot = nums[right]
    var i = left
    for (j in left until right) {
        if (nums[j] <= pivot) {
            val temp = nums[i]
            nums[i] = nums[j]
            nums[j] = temp
            i++
        }
    }
    val temp = nums[i]
    nums[i] = nums[right]
    nums[right] = temp
    return i
}
```
